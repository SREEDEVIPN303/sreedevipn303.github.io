# Sreedevi N P – Portfolio

Static portfolio site (`index.html`) plus sample projects in `projects/`.

## Publish on GitHub Pages
1. Create a **public** repository on GitHub (for example `sreedevi-portfolio`).
2. Upload everything in this folder so `index.html` sits at the top level of the repo.
3. Go to **Settings → Pages**. Under **Build and deployment → Source**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. After a minute or two the site is live at `https://<username>.github.io/sreedevi-portfolio/`.
5. (Optional) Open `index.html`, set `var REPO = "https://github.com/<username>/sreedevi-portfolio";` so the "View source" buttons appear.
